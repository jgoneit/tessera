# Tessera v0.1.0-alpha.6 — Brave placement fix

## 한국어

Brave 창을 방향키로 넘길 때 화면 밖으로 밀리던 문제를 고친 수정 릴리스입니다.

- **Brave 창이 화면 안에 맞게 배치됩니다:** 넓은 칸에서 좁은 칸으로 넘길 때 Brave가 이전 폭으로
  되돌아가 화면 오른쪽 밖으로 밀리던 문제를 고쳤습니다
  ([#11](https://github.com/jgoneit/tessera/issues/11)). 예를 들어 2×2 2열에서 3×2 3열로 넘기면
  이제 요청한 폭과 위치로 정확히 배치됩니다.
- 원인은 손쉬운 사용 보조 기능이 켠 Brave의 `AXEnhancedUserInterface` 속성이었습니다.
  이 속성이 켜져 있으면 Brave가 창 크기 변경을 애니메이션으로 처리합니다.
  Tessera는 Brave 창을 배치하는 짧은 동안에만 이 속성을 끄고, 끝나면 원래 값으로 되돌립니다.
- 이 처리는 Brave(정식·베타·나이틀리)에만 적용합니다. 다른 앱의 배치 방식과 격자·간격·언어·테마·단축키
  설정은 그대로 유지합니다.

### 설치와 업데이트

- macOS 14 이상, **Apple Silicon arm64**용 알파 릴리스입니다.
- alpha.4·alpha.5 사용자는 Tessera 메뉴 또는 설정에서 **업데이트 확인…**을 선택하세요.
- 신규 사용자와 alpha.3 이하 사용자는 아래 `Tessera-0.1.0-alpha.6-arm64.dmg`를 받아
  앱을 Applications로 복사하세요. `SHA256SUMS`로 파일 체크섬을 확인할 수 있습니다.
- 업데이트 후 macOS가 창 이동 권한을 다시 요구할 수 있습니다.
  [설치·손쉬운 사용 권한 안내](https://github.com/jgoneit/tessera/blob/v0.1.0-alpha.6/docs/INSTALL.md)를 참고하세요.

### 범위와 복구

로컬 ad hoc 서명과 기존 Sparkle 업데이트 서명을 사용합니다. Developer ID 서명·Apple 공증,
Intel·Universal 배포는 포함하지 않습니다. 앱의 최소 크기나 전체화면 상태에 따라 창 배치가 제한될 수 있습니다.
배치하는 동안 Brave의 화면 읽기 보조 상태가 아주 잠깐 바뀌었다가 복원됩니다.

복구가 필요하면 Tessera를 종료하고 [alpha.5](https://github.com/jgoneit/tessera/releases/tag/v0.1.0-alpha.5)의
DMG 또는 보관한 이전 앱을 다시 설치하세요. 환경설정은 삭제하지 말고, 필요하면 손쉬운 사용 권한을 갱신하세요.
업데이터는 자동 다운그레이드를 하지 않습니다.

## English

A corrective release for Brave windows that were pushed off-screen by directional placement.

- **Brave windows now stay on screen:** moving from a wider cell to a narrower one could leave Brave at its previous
  width, extending past the right edge of the display ([#11](https://github.com/jgoneit/tessera/issues/11)).
  For example, moving from 2×2 column 2 to 3×2 column 3 now lands at the requested width and position.
- The cause was Brave's `AXEnhancedUserInterface` attribute, which assistive features turn on and which makes Brave
  animate frame changes. Tessera turns the attribute off only while it arranges a Brave window, then restores it.
- This applies to Brave (release, Beta and Nightly) only. Other apps' placement and your grid, spacing, language, theme,
  and shortcut settings are unchanged.

### Install or update

- Alpha release for **Apple Silicon arm64**, requiring macOS 14 or later.
- On alpha.4 or alpha.5, choose **Check for Updates…** in Tessera's menu or Settings.
- New users and users of alpha.3 or earlier should download `Tessera-0.1.0-alpha.6-arm64.dmg`
  below and copy the app into Applications. `SHA256SUMS` contains the file checksum.
- macOS may require renewing Accessibility permission after updating.
  See the [installation and permission guide](https://github.com/jgoneit/tessera/blob/v0.1.0-alpha.6/docs/INSTALL.en.md).

### Scope and recovery

This release uses local ad hoc signing and the existing Sparkle update signing identity. It does not include
Developer ID signing, Apple notarization, or Intel/Universal distribution. App size limits and full-screen states
may restrict placement. Brave's assistive interface state changes only for the moment of placement and is restored.

To restore, quit Tessera and reinstall from the [alpha.5](https://github.com/jgoneit/tessera/releases/tag/v0.1.0-alpha.5)
DMG or a saved app. Keep your preferences and renew Accessibility permission if needed.
The updater does not automatically downgrade.
