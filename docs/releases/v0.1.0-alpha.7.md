# Tessera v0.1.0-alpha.7 — Gemini placement fix

## 한국어

Gemini 앱 창을 격자 사이로 넘길 때 배치가 중간에 멈추던 문제를 고친 수정 릴리스입니다.

- **Gemini 창이 끝까지 배치됩니다:** Gemini는 창 크기를 바꾼 뒤에도 '속성 미지원' 오류를 보고합니다.
  지금까지 Tessera는 이 오류에서 배치를 멈췄습니다. 그래서 2×2와 3×2 사이를 넘기면 창 크기만 바뀌고
  위치는 옮겨지지 않은 채 "배치 중단" 안내가 떴습니다. 이제 실제로 바뀐 창 상태를 읽어 판정하므로
  요청한 위치와 크기로 정확히 배치됩니다.
- 이 처리는 Tessera가 쓰기 직전에 '쓰기 가능'을 확인한 크기·위치에 대해 앱이 모순되게 답한 경우에만 적용합니다.
  응답 시간 초과, 권한, 대상 창 변경 같은 오류는 지금처럼 배치를 멈추고 안내합니다. 쓰기 횟수는 늘어나지 않습니다.
- 격자·간격·언어·테마·단축키 설정과 alpha.6의 Brave 수정은 그대로 유지합니다.

### 설치와 업데이트

- macOS 14 이상, **Apple Silicon arm64**용 알파 릴리스입니다.
- alpha.4 이후 사용자는 Tessera 메뉴 또는 설정에서 **업데이트 확인…**을 선택하세요.
- 신규 사용자와 alpha.3 이하 사용자는 아래 `Tessera-0.1.0-alpha.7-arm64.dmg`를 받아
  앱을 Applications로 복사하세요. `SHA256SUMS`로 파일 체크섬을 확인할 수 있습니다.
- **업데이트 후 단축키가 동작하지 않고 Tessera 설정 창이 뜨면** 손쉬운 사용 권한을 다시 허용해야 합니다.
  **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Tessera를 `−`로 삭제한 뒤
  `+`로 `/Applications/Tessera.app`을 다시 추가하고, Tessera 설정에서 **다시 확인**을 누르세요.
  [설치·손쉬운 사용 권한 안내](https://github.com/jgoneit/tessera/blob/v0.1.0-alpha.7/docs/INSTALL.md)도 참고하세요.

### 범위와 복구

로컬 ad hoc 서명과 기존 Sparkle 업데이트 서명을 사용합니다. Developer ID 서명·Apple 공증,
Intel·Universal 배포는 포함하지 않습니다. 앱의 최소 크기나 전체화면 상태에 따라 창 배치가 제한될 수 있습니다.

복구가 필요하면 Tessera를 종료하고 [alpha.6](https://github.com/jgoneit/tessera/releases/tag/v0.1.0-alpha.6)의
DMG 또는 보관한 이전 앱을 다시 설치하세요. 환경설정은 삭제하지 말고, 필요하면 손쉬운 사용 권한을 갱신하세요.
업데이터는 자동 다운그레이드를 하지 않습니다.

## English

A corrective release for Gemini windows whose placement stopped partway.

- **Gemini windows now finish placement:** Gemini reports an "attribute unsupported" error even after it resizes
  its window. Tessera stopped at that error, so moving between 2×2 and 3×2 columns resized the window without moving it
  and showed a "placement stopped" notice. Tessera now reads the window's actual state and lands it at the requested
  position and size.
- This applies only when an app contradicts the settable size or position Tessera confirmed just before writing.
  Timeouts, permission and target-window changes still stop placement with a notice. No writes are added.
- Grid, spacing, language, theme and shortcut settings, and alpha.6's Brave fix, are unchanged.

### Install or update

- Alpha release for **Apple Silicon arm64**, requiring macOS 14 or later.
- On alpha.4 or later, choose **Check for Updates…** in Tessera's menu or Settings.
- New users and users of alpha.3 or earlier should download `Tessera-0.1.0-alpha.7-arm64.dmg`
  below and copy the app into Applications. `SHA256SUMS` contains the file checksum.
- **If shortcuts stop working and Tessera's Settings window appears after updating,** renew Accessibility permission.
  In **System Settings → Privacy & Security → Accessibility**, remove Tessera with `−`, add
  `/Applications/Tessera.app` again with `+`, then choose **Check Again** in Tessera's Settings.
  See also the [installation and permission guide](https://github.com/jgoneit/tessera/blob/v0.1.0-alpha.7/docs/INSTALL.en.md).

### Scope and recovery

This release uses local ad hoc signing and the existing Sparkle update signing identity. It does not include
Developer ID signing, Apple notarization, or Intel/Universal distribution. App size limits and full-screen states
may restrict placement.

To restore, quit Tessera and reinstall from the [alpha.6](https://github.com/jgoneit/tessera/releases/tag/v0.1.0-alpha.6)
DMG or a saved app. Keep your preferences and renew Accessibility permission if needed.
The updater does not automatically downgrade.
