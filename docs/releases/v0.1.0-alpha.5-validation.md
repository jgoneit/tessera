로컬 검증 / Local validation: 2026-10-04. 공개 검증 / Public delivery: 2026-10-05.
대상 / Target: `0.1.0-alpha.5`, build `5`, macOS arm64.

### 실제 로컬 업데이트

공개 alpha.4 DMG를 다시 다운로드하여 체크섬을 검증했다. 그 앱의 사본에 시험용 loopback 피드,
별도 Sparkle 설정 도메인, 자동 확인 끔 및 로컬 네트워크 메타데이터만 적용하고 ad hoc 재서명했다.
출발점의 기능 코드를 다시 빌드하지 않았으며, 대상은 수정하지 않은 최종 alpha.5 DMG이다.

| 시나리오 | 관찰 결과 |
| --- | --- |
| 서명 없는 피드 | Sparkle이 피드 서명 오류로 거부, alpha.4 실행 파일 해시 유지 |
| 업데이트 안내 닫기 | 설치하지 않고 alpha.4 실행 파일 해시 유지 |
| 한 바이트 변조된 시험 DMG | 다운로드 후 서명 오류로 설치 전에 거부, alpha.4 실행 파일 해시 유지 |
| 정상 DMG | 다운로드 → 설치 & 재실행 → alpha.5 빌드 5 실행 |
| 설치된 내용 | 최종 후보 실행 파일 해시 일치, 공개 피드 복원, 시험용 도메인·ATS 예외 없음 |
| 사용자 설정 | 전체 환경설정 의미 값 비교에서 변경 키 없음 |

로컬 서버를 종료하고 시험용 Sparkle 설정 도메인을 제거했다. 일반 Tessera 설정은 삭제하지 않았다.
성공한 업데이트 결과를 `/Applications/Tessera.app`에 설치하고 코드 서명·단일 실행 프로세스를 확인했다.
사용자 macOS 인증 후 기존 Tessera 권한을 새 설치본으로 갱신했으며 앱에서 창 배치 준비 상태를 확인했다.
이 단계는 로컬 시험 피드에서의 설치 증거이며 공개 피드의 전달 증거와 구분한다.

- [공개 업데이트 피드](https://jgoneit.github.io/tessera/appcast.xml)는 서명된 배포 후보 피드와 일치하며,

- 설치된 `/Applications/Tessera.app`에서 공개 피드로 **업데이트 확인…**을 실행했다.
  2026-10-05 10:26 KST에 alpha.5가 최신 버전이라는 안내와 창 배치 준비 상태를 확인했다.

공개 확인에는 새 설치를 포함하지 않는다. alpha.4에서 alpha.5로의 설치와 설정 보존 증거는
위의 로컬 업데이트 시험에 해당한다. 배포 파일과 서명은 공개 과정에서 변경하지 않았다.

### 실제 창 배치와 검증 범위

기존 개발 빌드의 듀얼 화면 43회 배치, 화면 전환 10회, 좌우 바깥 순환 각각 3회 기록은
[다중 모니터 검증](../multi-monitor-validation.md)에 있다. 해당 실행 파일과 이번 배포 후보는 구분한다.
alpha.5의 선택기 이동·숫자·최대화와 Brave 크기 보정 실측은 대기 중이다.
2026-10-04 로컬 시험 시점에는 외장 화면 한 대만 연결되어 있었다.

물리적 상하 배치·3대 화면·연결 해제, 다른 Mac과 macOS 14에서의 설치는 자동 검사 또는 미검증 범위이다.

### 복구와 증거

기존 개발 앱과 환경설정은 작업 공간의 `dist/release-alpha5/backup/`에 보관했다.
이전 공개 alpha.4 앱도 `dist/release-alpha5/official-alpha4/`에 보관했다.
검사 로그, 서버 요청 로그, `local-update-source.json`, `local-update-results.json`은
`dist/release-alpha5/`에 있으며 개인 설정 사본과 함께 Git에 포함하지 않는다.
공개 다운로드 결과, Pages HTML과 `publication-receipt.json`은
`dist/release-alpha5/public-20261005/`에 보관했다.
일반 사용자의 수동 복구 절차는 [설치 안내](../INSTALL.md#이전-버전으로-복구하기)를 따른다.

## English

### Automated checks and candidate

Swift tests passed: 72 Core + 181 App = 253. The release bundle, nested signatures, updater configuration,
runtime paths, 13 public-key verification cases, 49 website tests, JavaScript syntax, and diff whitespace checks passed.
The DMG was mounted read-only to inspect the app, Applications link, and bilingual installation note, then unmounted.
The existing signing identity signed the feed and DMG. The feed retains build 4 alongside build 5.
Candidate hashes are listed above; these checks do not establish notarization or execution on other Macs.

### Actual local update

The public alpha.4 DMG was downloaded and checksum-verified. Its app was copied, given loopback test feed settings,
an isolated Sparkle defaults domain, disabled automatic checks and local-network metadata, then ad hoc re-signed.
Its application source was not rebuilt. The target was the unchanged final alpha.5 candidate DMG.

Sparkle rejected an unsigned feed and a DMG with one byte altered. Closing the update prompt also left the
alpha.4 executable unchanged. With the valid DMG, Download → Install & Relaunch reached alpha.5 build 5.
Its executable matched the candidate, the public feed was restored, and the test defaults domain and ATS exception
were absent. Semantic comparison found no changed preference keys.

The loopback server was stopped and the test-only Sparkle defaults domain removed. Ordinary preferences were retained.
The updated app was installed at `/Applications/Tessera.app`, its signature and single running process were checked,
and Accessibility readiness was confirmed after the user authenticated renewal of the existing permission.
This establishes local-feed installation, separate from public-feed delivery.

Public verification did not perform another installation. The alpha.4-to-alpha.5 installation and preference
preservation evidence comes from the local update above. Publication did not alter the signed assets or feed.

### Native validation boundaries

The earlier development build's 43 native placements, 10 display crossings, and three wraps in each direction are
recorded separately. The alpha.5 candidate's picker movement, number/Maximize selection, and Brave size correction
are pending native validation; only the external display was connected during the 2026-10-04 local run.
Physical vertical arrangements, three displays, unplugging, other Macs, and macOS 14 are not covered by this native run.

Backups and local evidence remain in `dist/release-alpha5/`, excluded from Git.
Public downloads, Pages HTML, and `publication-receipt.json` are retained in `dist/release-alpha5/public-20261005/`.
See the [English recovery guide](../INSTALL.en.md#restore-a-previous-version) for manual restoration.
