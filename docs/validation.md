# Tessera v0.1 검증 기록

한국어 | [English](validation.en.md)

상태: 구현 및 검증 진행 중. 아래 항목을 모두 확인하기 전에는 전체 v0.1 완료로 간주하지 않습니다.
사용자의 “잘된다” 확인은 이전 아이콘·상하 이동 버전의 기본 동작에 대한 기록입니다.
이전 네 방향 전역 단축키 버전은 해당 번들의 접근성 재등록 후 사용자가 “이제 이동함”으로 기본 이동을 확인했습니다.
이전 다중 격자 버전은 테스트 131개와 release 번들 검증, Seal Acceptance를 통과했습니다. 실제 로그에서
2×2+3×2 후보 요청과 일부 창 배치 성공을 확인했지만, 오른쪽 가장자리에서 2×2로 넓힐 때 제약 결과가 반복됐습니다.
이전 가장자리 변경은 크기 변경 전에 필요한 공간을 확보하는 수정입니다. 해당 수정은 자동 테스트 158개와 release 번들
생성·서명 검증을 통과했습니다. 접근성에 새 번들을 재등록한 뒤 ChatGPT 창의 오른쪽 ⅓ → 오른쪽 절반 확대를
실제 프레임 로그와 사용자 “이제 오른쪽 절반으로 넓어짐” 답변으로 확인했습니다.
설정·선택기·결과 안내의 UI와 한국어·영어, 시스템·라이트·다크 테마를 지원합니다.
메뉴바에는 단색 template 아이콘 하나를 표시합니다. 현재 변경은 설정 헤더·권한 상태·여백의 압축,
키캡 배경의 약한 음영과 선택기의 반응형 조작 안내입니다.
후속 로컬 설치 변경은 헤더 설명 문구 제거, 응용 프로그램 폴더 설치와 ad hoc DMG 포장입니다.
이전 버전의 성공을 이번 번들이나 모든 다중 격자 조합의 통과 증거로 확대하지 않습니다.

## 환경

- macOS 26.6.2, Apple Silicon
- Swift 6.4, Command Line Tools
- 최초 탐지 화면: TFG40U12PW 한 대, 5120×2160pt, scale 1, visible frame `(0, 0, 5120, 2130)`
- 최소 지원 버전 설정: macOS 14. 실제 macOS 14에서의 실행은 별도 미검증입니다.

  인터넷 다운로드 후 Gatekeeper 동작, 다른 Mac 설치, Intel·macOS 14 실제 실행은 별도 미검증입니다.
  이번 설치본의 실제 창 배치 전체와 기존 다중 화면 실기도 미완료로 유지합니다.
- 기존 Seal Task·Run은 보존하며 이 후속 변경의 Acceptance로 재사용하지 않습니다.
  미추적 사용자 시안이 있는 worktree이므로 이번 요청의 Seal 자동 활성화는 생략했습니다.

## 설정·선택기 UI 다듬기

- 설정의 기본 680×800pt·최소 640×620pt·스크롤을 유지하고 바깥 여백 24pt, 섹션 간격 16pt,
  헤더 아이콘 48pt·이름 22pt를 적용했습니다. 권한 허용은 작은 상태 행, 미허용은 설명 카드로 구분합니다.
  두 상태에서 설정 열기·다시 확인 버튼과 접근성 이름을 유지합니다.
- 화면 표시·단축키 카드의 내부 여백은 16pt, 격자 카드는 기존 20pt입니다. 단축키 접힘과 오류 시 펼침,
  녹화·적용·저장 동작은 유지합니다. 키캡은 배경에만 1pt 아래 방향의 약한 그림자를 추가하며,
  대비 증가에서는 그림자를 없애고 테두리를 강조합니다.
- 선택기는 중복 높이 배지를 제거하고 현재 배치 문구와 28pt의 두 줄 상태 공간을 유지합니다.
  네 묶음의 조작 안내가 폭에 따라 한 줄 또는 두 줄로 표시됩니다. 숫자 범위는 격자에 맞춰 1–4/6/8로 바뀝니다.
  en/ko 문구를 함께 추가했으며 Core·AX·키 입력·저장 형식·메뉴 아이콘은 변경하지 않았습니다.
- 사용자 시안 `docs/design_prototype.html`은 로컬 원본 그대로 보존하며 버전 관리·PR에서 제외합니다.

- `TESSERA_UI_PREVIEW_DIR="$PWD/.build/ui-polish-previews" swift test`에서 174개(Core 57, App 117)가 통과했습니다.

## 다중 격자 구현과 검증 범위

- 선택 가능한 격자는 2×2·3×2·4×2이며 하나 이상 유지합니다. 초기값은 3×2 하나입니다.
  메뉴와 설정은 같은 선택 목록을 사용하고, Settings에서는 마지막으로 남은 체크박스를 해제할 수 없게 합니다.
- 좌우 후보는 선택한 격자들의 열 중심을 화면 위치 순서로 합칩니다. 예를 들어 2×2+3×2는
  `3×2 1열 → 2×2 1열 → 3×2 2열 → 2×2 2열 → 3×2 3열` 순서입니다.
  상하는 현재 격자·열을 유지하며 위·전체·아래 단계만 바꾸고, 좌우는 그 높이 단계를 유지합니다.
- 현재 프레임이 활성 후보의 위·전체·아래 프레임과 일치하면 그 선택을 복원합니다. 그렇지 않으면
  선택기는 원래 창 중심에 가장 가까운 열 전체를 강조하며, 동률은 왼쪽을 선택합니다. 첫 좌우 입력은
  원래 창 중심에서 입력 방향에 있는 가장 가까운 후보를 고릅니다. 선택기를 열기만 해서는 배치하지 않습니다.
- 선택기는 현재 후보의 격자를 표시합니다. 숫자·숫자패드는 표시 중인 격자의 1–4/1–6/1–8만 선택하며,
  범위 밖 숫자는 소비하되 배치하지 않습니다. 클릭은 표시된 격자와 Zone을 함께 전달합니다.
- `tessera.enabledLayouts.v1`에는 raw value 배열을 2×2·3×2·4×2 순서로 저장합니다. 유효한 중복 값은
  정규화하고, 빈 배열·잘못된 타입·알 수 없는 항목이 있는 배열은 전체를 3×2 하나로 복구합니다.
  새 키가 없을 때만 기존 `tessera.defaultLayout`을 한 개 선택으로 이전하며, 새 목록 저장 후 이전 키를 제거합니다.
  Gap과 네 방향 단축키 저장 계약은 유지합니다.
- 설정 변경 취소는 Coordinator가 공유 설정의 변경을 동기적으로 관찰하는 경로에서 처리합니다.
  Settings만의 지연된 onChange에 의존하지 않으며 메뉴에서 바꿀 때도 같은 경로를 사용합니다.

설정 테스트에는 가능한 일곱 개 선택 조합, 마지막 항목 제거 차단, 중복 정규화, 새 키 우선순위,
기존 단일 값 이전, 손상된 저장값 복구를 추가했습니다. 다중 격자 버전의 자동 검증은 위의 131개 결과와
