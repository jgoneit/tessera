## 로컬 브라우저 확인

Codex 인앱 브라우저에서 실제 UI 조작으로 확인했다.

- 한국어/영어 × 라이트/다크 전환. 1280px 데스크톱, 375px 및 320px 좁은 화면에서
  설명과 컨트롤을 확인했으며 가로 페이지 넘침은 없었다. 좁은 화면의 상단 다운로드는
  접근성 이름을 유지한 아이콘으로 표시하고 본문 다운로드 버튼은 글자를 유지한다.
- 2×2+3×2 및 전체 격자 선택, 위칸·열 전체·아래칸 상태를 언어 전환 전후로 유지했다.
  격자를 체크한 뒤 바로 방향키 입력이 동작하고, 4×2에서 숫자 8로 아래칸을 선택한 뒤
  위 방향키 한 번으로 열 전체로 전환했다.
- 열 수를 바꾸지 않고 언어만 전환해도 모든 Zone의 접근성 이름과 현재 배치 문구가
  새 언어로 바뀐다. 영어 화면에서 한국어는 의도된 언어 전환 버튼에만 표시됐다.
- 언어 전환 후 새로고침과 언어 지정 없는 URL에서 저장한 선택이 적용됐다.
  명시적인 `?lang=ko`/`?lang=en`은 저장값보다 우선했다.
- 앵커 이동 → 언어 변경 → 브라우저 뒤로 가기 후 URL과 화면 언어가 일치했고,
  선택한 격자·배치 상태는 유지됐다. 브라우저 콘솔 오류는 없었다.

## 공개 배포 확인

- 배포 소스: `d7458d906d4fb7691c7213ce69fbb66718a6b442`.
  [GitHub Actions 35439256103](https://github.com/jgoneit/tessera/actions/runs/35439256103)의
  웹 검사와 GitHub Pages 배포가 통과했다.
- 공개 HTML·CSS·app/navigation/i18n 모듈·아이콘 6개가 모두 HTTP 200으로 응답했고
  로컬 소스와 바이트 단위로 일치했다. 모듈은 JavaScript MIME으로 제공됐다.
- 기존에 열려 있던 공개 페이지를 새로고침하여 새 언어 버튼을 확인했다.
  2×2+3×2 선택 → 방향키 이동 → 영어 전환 후 선택·높이가 유지됐고,
  영어 화면의 아래 방향 버튼으로 위칸에서 열 전체로 이동했다.
- [영문 공개 주소](https://jgoneit.github.io/tessera/?lang=en)를 새로고침해도 영어 제목과
  본문이 표시됐다. 공개 페이지에서 기록된 브라우저 콘솔 오류는 없었다.

## 검증 범위

- 브라우저 동작과 정적 번역을 검증한 결과다. VoiceOver 실기와 다른 브라우저 엔진은
  이번에 검증하지 않았다. 네이티브 앱의 창 이동·외부 화면 검증을 대신하지 않는다.
- JavaScript를 실행하지 않는 링크 미리보기는 영어 URL에서도 한국어 정적 메타데이터를
  사용할 수 있다. JavaScript가 꺼진 경우 다운로드와 한·영 문서 안내를 제공한다.
