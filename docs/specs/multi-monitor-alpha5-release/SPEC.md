# Tessera 다중 모니터 개선 alpha.5 릴리스

Status: Ready

## 목표

다중 모니터 창 배치 개선을 alpha.5로 공개한다. 기존 alpha.4 사용자는 앱 안에서
업데이트하고 기존 설정으로 다시 사용할 수 있으며, 신규 사용자는 공식 다운로드에서
같은 배포 앱을 설치할 수 있어야 한다.

## 릴리스 식별

| 항목 | 값 |
| --- | --- |
| 표시 버전 | `0.1.0-alpha.5` |
| Git 태그 | `v0.1.0-alpha.5` |
| CFBundleShortVersionString | `0.1.0` |
| CFBundleVersion | `5` |
| 배포 채널 | alpha 사전 릴리스 |

| 체크섬 파일 | `SHA256SUMS` |
| 업데이트 피드 | `https://jgoneit.github.io/tessera/appcast.xml` |

## 범위

- 기존 다중 모니터 명세의 방향 이동, 좌우 바깥 경계 순환, 목적지 작업 영역과 배율 적용.
- 선택기의 목적지 화면 추적, 이전 화면의 크기 제한이 남는 앱의 화면 전환 보정.
- 버전 정보, DMG, 체크섬, 서명된 피드, 한국어·영어 릴리스와 다운로드 안내.
- 실제 업데이트 설치·재실행·설정 보존 및 기존 배포본을 이용한 복구 경로.

범위 밖: 모니터별 격자·간격, 실행 취소, 모니터 직접 전환 단축키, 새 배치 방식,
Spaces 전체화면, Intel·Universal 배포, Developer ID·공증, 정식 전환, 서명키 교체.

## 인터페이스와 제약

- 앱과 피드의 버전·빌드는 일치하고 태그 소스에 기능과 버전 변경이 포함된다.
- 일반 다운로드와 업데이터가 동일한 검증된 DMG 바이트를 사용한다.
- 기존 공개키로 검증 가능한 서명을 사용한다. 개인키와 시험용 피드·설정은 배포하지 않는다.
- 최종 앱에는 시험용 `SUFeedURL`, `SUDefaultsDomain`, ATS 예외가 없어야 한다.
- 기존 릴리스 자산을 보존하며 공개한 동일 파일명의 바이트를 교체하지 않는다.
- 수정 배포는 더 높은 빌드를 사용한다. 자동 다운그레이드를 복구 수단으로 삼지 않는다.
- 격자·간격·단축키·언어·테마 설정을 보존한다. 필요한 경우 기존 손쉬운 사용 권한 갱신을 안내한다.
- 실제 검증 장치와 자동 검사 범위를 구분하며 다른 Mac 전체에서의 동작을 보장하지 않는다.

## 설계 결정

기존 alpha 채널, 전체 DMG, GitHub Releases·Pages 및 기존 서명 체계를 유지한다.
후속 기능은 별도 변경으로 다룬다. 공개 파일 생성만으로 완료하지 않으며, 기존 앱의
업데이트·재실행과 배포 기능 사용까지 완료 조건에 포함한다.

## 수용 조건

### AC-1 — 배포본의 다중 모니터 동작

- 기존 [다중 모니터 명세](../multi-monitor-navigation/SPEC.md)의 AC-1–AC-6을 만족한다.
- 실제 듀얼 모니터에서 인접 화면으로 이동한다. 왼쪽 바깥 경계는 맨 오른쪽 화면의
  마지막 열로, 오른쪽 바깥 경계는 맨 왼쪽 화면의 첫 열로 연결된다.
- 선택기가 목적지로 이동하고 화면 이름·격자를 갱신하며 입력을 유지한다.
  숫자·클릭·최대화는 같은 대상 창과 목적지 화면에 적용된다.
- Brave의 작은 화면→큰 화면 이동에서 이전 화면 제한만으로 높이가 남지 않는다.
  실제 앱 크기 제한이 유지되면 정확하게 안내한다.
- 단일 화면, 최대화·반쪽 배치, 반복 입력 및 취소 동작을 유지한다.

### AC-2 — 기존 사용자의 업데이트와 설정 보존

- alpha.4에서 업데이트 확인·다운로드·설치·재실행 후 공개 배포본과 동일한 alpha.5 빌드 5가 실행된다.
- 격자·간격·단축키·언어·테마가 유지되고 기존 단축키를 사용할 수 있다.
- 손쉬운 사용 권한 갱신이 필요하면 갱신 후 창 배치를 사용할 수 있다.

### AC-3 — 공개 배포물과 업데이트 피드의 일치

- GitHub 사전 릴리스의 태그, DMG와 SHA256SUMS가 공개된다.
- 공개 파일은 검증한 후보와 동일하고 체크섬·서명 검증을 통과한다.
- 공개 피드는 alpha.5 빌드 5와 실제 파일 URL을 가리키며 기존 신뢰 키로 검증된다.
- 태그의 소스에는 배포 기능과 버전 변경이 포함된다.

### AC-4 — 배포 안내의 일치와 정확성

- 한국어·영어 릴리스 노트, README, 설치 안내, 웹사이트의 버전·링크·기능 설명이 일치한다.
- 화면 간 이동·바깥 경계 순환·선택기 이동·앱 크기 제한을 설명한다.
- 지원 환경, 서명·공증 범위, 알려진 한계를 실제 상태대로 안내한다.
- alpha.3 이하의 직접 DMG 설치 필요성을 유지한다.
- 신규 사용자는 공식 안내를 통해 같은 alpha.5 앱을 설치할 수 있다.

### AC-5 — 업데이트 실패와 복구

- 취소 또는 변조된 피드·DMG의 무결성·서명 검증 실패는 기존 앱과 설정을 손상하지 않는다.
  검증에 실패한 파일은 설치되지 않는다.
- 이전 릴리스 파일에 접근할 수 있고 수동 복구 방법이 안내된다.
- 잘못된 업데이트를 철회할 때에도 유효하게 서명된 피드를 제공할 수 있다.
  이미 설치된 앱의 수정본은 더 높은 빌드로 제공한다.
